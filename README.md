# Diabetes and Heart Disease Prediction

## Overview

Diabetes and Heart Disease Prediction is a machine learning-based web application developed using Python and Flask. It allows users to enter relevant health parameters and obtain prediction results for diabetes and heart disease.

The project demonstrates how machine learning models can be integrated into a web application to provide an interactive user experience.

## Features

- **Diabetes Prediction** — Predicts the likelihood of diabetes based on relevant health parameters.
- **Heart Disease Prediction** — Provides heart disease prediction functionality.
- **Web Interface** — Enables users to interact with the application through a web browser.
- **User Authentication** — Includes user registration and login functionality.
- **Prediction Results** — Displays results generated by the machine learning models.
- **Model Integration** — Uses saved model files to generate predictions.
- **PDF Generation** — Includes PDF-generation functionality where supported by the application.
- **AI Integration** — Includes Gemini AI integration where configured.

## Installation and Setup

Follow these steps to run the project locally.

### Prerequisites

- Python installed on your computer.
- Git installed, or download the repository as a ZIP file.
- An internet connection to download the required Python packages.

Python 3.13.9 worked with the dependencies in the development environment. Compatibility with other Python versions may vary.

### 1. Clone the Repository

Open a terminal and run:

```bash
git clone https://github.com/IsantChaudhary/Diabetes-and-Heart-Disease-Prediction.git
```

### 2. Navigate to the Project Directory

```bash
cd Diabetes-and-Heart-Disease-Prediction
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

Activate the environment on Windows:

```powershell
.\venv\Scripts\Activate.ps1
```

If PowerShell blocks activation, you can use Command Prompt instead:

```bat
venv\Scripts\activate.bat
```

On macOS or Linux:

```bash
source venv/bin/activate
```

### 4. Install Dependencies

Run:

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

### 5. Configure Environment Variables

If the application uses Gemini AI functionality, it requires a valid Gemini API key.

Create a `.env` file in the project root directory and add:

```text
GEMINI_API_KEY=your_api_key_here
```

Replace `your_api_key_here` with your own API key. Keep the `.env` file private and never commit it to GitHub.

If the application requires additional environment variables, configure those as well.

### 6. Run the Application

Start the Flask application:

```bash
python app.py
```

Open the local URL displayed in the terminal in your web browser. It is typically:

`http://127.0.0.1:5000`

The application runs locally on your computer; uploading the code to GitHub does not automatically host it online.
