# Diabetes and Heart Disease Prediction

## Overview

Diabetes and Heart Disease Prediction is a machine learning-based web application developed using Python and Flask. It allows users to enter relevant health parameters and obtain prediction results for diabetes and heart disease.

The project demonstrates the integration of machine learning models with a web application.

## Features

- **Diabetes Prediction** — Predicts the likelihood of diabetes based on input health parameters.
- **Heart Disease Prediction** — Provides heart disease prediction functionality.
- **Web Interface** — Allows users to interact with the application through a browser.
- **User Authentication** — Includes registration and login functionality.
- **Prediction Results** — Displays results generated by the prediction models.
- **Model Integration** — Uses saved model files for predictions.

## Technologies Used

- Python
- Flask
- Machine Learning
- Scikit-learn
- HTML and CSS
- JavaScript
- Jupyter Notebook

## Project Structure

- `app.py` — Main Flask web application.
- `model.py` — Model-related functionality.
- `model.pkl` — Saved machine learning model.
- `accuracies.pkl` — Saved model accuracy information.
- `diabetes.ipynb` — Jupyter Notebook for model development and analysis.
- `templates/` — HTML templates for the web interface.
- `static/` — Static assets such as CSS, JavaScript, and images.
- `data/` — Dataset files, if included.
- `requirements.txt` — Python package dependencies.

## Installation and Setup

Follow these steps to run the project on your local computer.

### Prerequisites

- Python installed on your computer.
- Git installed, or download the repository as a ZIP file.
- A compatible Python environment and the required project files.

### 1. Clone the Repository

Open a terminal and run:

```bash
git clone https://github.com/IsantChaudhary/Diabetes-and-Heart-Disease-Prediction.git
```

### 2. Navigate to the Project Directory

```bash
cd Diabetes-and-Heart-Disease-Prediction
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

Activate the environment on Windows:

```bash
venv\Scripts\activate
```

On macOS or Linux:

```bash
source venv/bin/activate
```

### 4. Install Dependencies

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 5. Configure Environment Variables

If the application uses the Gemini API or other environment variables, configure the required values before running it.

For example, if Gemini integration is enabled, create a `.env` file in the project root:

```text
GEMINI_API_KEY=your_api_key_here
```

Replace the placeholder with your own API key. Never publish actual API keys, passwords, or other secrets on GitHub.

### 6. Run the Application

Start the Flask application:

```bash
python app.py
```

Open the local address displayed in the terminal in your web browser. It is typically:

`http://127.0.0.1:5000`

## How to Use

1. Start the application.
2. Open it in your web browser.
3. Register or log in if required.
4. Choose the relevant prediction feature.
5. Enter the requested health parameters.
6. Submit the information to view the prediction results.
